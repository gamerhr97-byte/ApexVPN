# Apex VPN 1.11.0 — سورس کامل پروژه

این آرشیو، سورس پروژه، فایل‌های دارایی، هسته‌های Windows/Linux، runtime ویندوز، ابزارهای ساخت، آزمون‌ها، مجوزها و راهنمای تحویل به هوش مصنوعی بعدی را دارد. برای شروع `NEXT_AI_HANDOFF_FA.md` و سپس `AGENTS.md` را بخوانید.

فایل آپدیت کوچک و آماده در `artifacts/ApexVPN-1.11.0-Quick-Update.exe` قرار دارد. این updater فقط روی نصب موجود Apex VPN 0.10.7 اعمال می‌شود؛ Apex و آیکون سینی را قبل از اجرا ببندید. تنظیمات و اشتراک‌ها حفظ می‌شوند. این فایل نصاب نصب تازه نیست.

نسخهٔ برنامه و PE لانچر/میزبان 1.11.0 است؛ نام بعضی دارایی‌ها و مسیر نصب برای حفظ سازگاری با نسخهٔ نصب‌شده، عبارت 0.10.7 یا NekoRayNext دارد.

محدودیت: ساختار updater و فایل‌های بسته بررسی شده‌اند، اما نصب تعاملی و اجرای واقعی روی Windows در این محیط انجام نشده است. برای راهنمای فنی و وضعیت دقیق به `NEXT_AI_HANDOFF_FA.md` مراجعه کنید.
