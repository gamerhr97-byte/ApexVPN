# بررسی Apex VPN 0.10.4

۲۱۱ تست موفق، ۲ تست ردشده به دلیل محدودیت محیط، صفر شکست. اجرای نهایی pytest با Qt offscreen در Linux x64؛ گزارش XML همراه سورس است.

- تست واقعی محلی Xray: HTTP/HTTPS، آمار، VLESS encryption، TLS و Reality روی gRPC/XHTTP، HTTPUpgrade، تعویض سرور، قطع/خرابی، subscription و اتصال Trojan روی WebSocket/TLS با FinalMask آرایه‌ای. CA موقت آزمون صریحاً مورد اعتماد fixture است؛ TLS تولیدی تغییر نکرده.
- نمونه ماسک با lengths صفر/۱۰۴/۱ و ماسک دوم، cs و fragment placeholder به config تبدیل و توسط Xray واقعی تأیید ساختاری شد. اتصال به سرور عمومی نمونه کاربر تأیید نشده است؛ لینک شخصی در تست/بسته ذخیره نشده.
- Xray جدید، مقصدهای خصوصی را در freedom سرور محدود می‌کند. فقط سرورهای محلی fixture قانون allow برای loopback دارند؛ قانون تولیدی برای عبور از این محدودیت اضافه نشده.
- تست مالکیت Free، حذف موقت، بازگشت در refresh، حفظ اشتراک خصوصی، نصب یک‌باره کاتالوگ و refresh همه منابع در launch؛ کنترل گروه Free و دسته تنظیمات ۱۵.
- تست تاریخچه SQLite: baseline صحیح آداپتور، صفر نشدن تاریخچه با restart، reset شمارنده، بازه زمانی، جداسازی VPN و سیستم و جلسه جدید.
- تست حرکت: کلیک واقعی دکمه/چک‌باکس، حفظ geometry، توقف تایمر و Reduced Motion. لودینگ و بخش مصرف نیز با Qt رندر و بازبینی شدند. نرخ ۶۰FPS و GPU روی دستگاه ویندوز اندازه‌گیری نشده.
- محتوای عمومی چهار ساب با خواننده سازگار با شبکه میزبان دریافت و parse شد: ProxyCollector=455، Alirewa=100، Patterniha=33، Mahsa=35. این تعداد لحظه‌ای است و تأیید سلامت نودها یا دانلود مستقیم/پروکسی تولیدی نیست. مسیریابی تولیدی برای عبور از محدودیت محیط تغییر نکرد.
- دو skip: تست تشخیص process route و ترافیک sing-box به محدودیت سیستم Linux این محیط وابسته‌اند؛ پیام دقیق در HANDOFF_VALIDATION.json/XML ثبت شده است.
- لانچر و میزبان native با Zig برای Windows x64 ساخته شدند، resource نسخه 0.10.4 و آیکون A دارند. هش دو core در runtime-hashes.json ثبت و ورودی‌های دانلود رسمی با lockfile بررسی شدند. Runtime همراه نسخه قبلی قبل از استفاده با CRC فایل‌های ZIP مرجع مقایسه شد. هر دو ZIP نهایی نیز CRC بررسی شدند.

## مواردی که این محیط تأیید نمی‌کند

اجرای واقعی Windows، WinINET، DPAPI، نام/آیکون Task Manager، مسیر شبکه اپراتور کاربر، BCrypt ویندوز، شمارنده آداپتور ویندوز و عملکرد همه نودهای عمومی. کد Windows برای BCrypt و GetIfEntry2 پیاده شده ولی تست عملی Windows لازم است. بسته portable اجرایی است؛ نصب‌کننده یا امضای عمومی ناشر نیست. پشتیبانی همه پروتکل‌ها و تمیزی واقعی همه IPها ادعا نمی‌شود.
