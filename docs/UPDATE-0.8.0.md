# راهنمای آپدیت Shadow Box به 0.8.0

این فایل مخصوص نسخه مدرن 0.7.0 روی ویندوز ۱۰ و ۱۱، پردازنده Intel/AMD x64 است؛ روی نسخه Legacy ویندوز ۷ نریزید. این بسته آپدیت است و به‌تنهایی نصب کامل محسوب نمی‌شود. پیش‌نیاز جدید یا دانلود لازم ندارد.

## روش نصب

۱. اتصال را قطع کنید و از منوی آیکون کنار ساعت، Quit را بزنید؛ فقط بستن پنجره کافی نیست.
۲. روی میان‌بر Shadow Box راست‌کلیک و Open file location را بزنید تا پوشه اصلی برنامه باز شود. مسیر معمول نصب: `%LOCALAPPDATA%\Programs\ShadowBox`. پوشه اصلی دارای `ShadowBox.exe` و پوشه‌های `runtime` و `core` است. اگر فقط میان‌بر را دیدید، همین کار را روی آن تکرار کنید.
۳. برای احتیاط یک کپی از پوشه برنامه و داده‌ها نگه دارید. داده‌های نسخه نصبی در `%LOCALAPPDATA%\NekoRayNext` هستند. در نسخه پرتابل، پوشه `data` کنار فایل اجرایی قرار دارد. داده‌ها با حساب ویندوز شما محافظت می‌شوند؛ نسخه پشتیبان را روی همان حساب نگه دارید.
۴. ZIP آپدیت را Extract کنید. **محتویات داخل پوشه `NekoRayNext`** را داخل پوشه اصلی برنامه کپی کنید و Replace را بزنید. خود پوشه NekoRayNext را به‌صورت یک زیرپوشه جدید کپی نکنید. `runtime`، `core`، `data` و `portable.flag` نسخه قبلی را حذف نکنید. پوشه دانلود را به‌تنهایی اجرا نکنید.
۵. `ShadowBox.exe` را اجرا کنید. شماره نسخه باید 0.8.0 باشد. سرورها و ساب‌ها باقی می‌مانند. اگر خطای فایل در حال استفاده دیدید، برنامه هنوز باز است؛ Quit کنید و دوباره کپی کنید.

## تنظیم اتصال مستقیم

۱. اتصال را قطع کنید و به تنظیمات ← **۱۴. اتصال مستقیم سایت‌ها و برنامه‌ها** بروید.
۲. «فعال‌سازی استثناهای اتصال مستقیم» را روشن کنید. «اتصال مستقیم سایت‌های .ir» به‌صورت پیش‌فرض در این بخش روشن است، ولی تا فعال‌کردن کل بخش و اعمال تغییرات اجرا نمی‌شود.
۳. برای سایت‌های دیگر، هر خط یک دامنه بنویسید؛ مانند `example.com`. زیردامنه‌ها هم مستقیم می‌شوند. از `https://`، مسیر، `*` و لینک ساب استفاده نکنید. برای حذف، همان خط را پاک کنید.
۴. برای برنامه یا بازی، «افزودن برنامه یا بازی» را بزنید و فایل EXE اصلیِ متصل به اینترنت را انتخاب کنید. یا هر خط یک نام مانند `game.exe` بنویسید. فایل اصلی بازی ممکن است با لانچر متفاوت باشد. مسیر کامل دقیق‌تر است؛ حروف کوچک و بزرگ را مطابق فایل نگه دارید.
۵. «اعمال تغییرات» را بزنید، دوباره وصل شوید و برنامه/بازی موردنظر را ببندید و باز کنید تا اتصال‌های قدیمی آن بسته شوند.

ترافیک مستقیم از IP واقعی شما استفاده می‌کند. .ir به معنی همه سایت‌ها و IPهای ایران نیست؛ اگر سایت از دامنه دیگری برای منابعش استفاده کند، آن دامنه را نیز جداگانه اضافه کنید. نام دامنه باید در درخواست یا اطلاعات قابل‌تشخیص اتصال موجود باشد؛ اتصال صرفاً با IP و نام پنهان/رمزشده ممکن است شناسایی نشود.

این نسخه حالت System Proxy و HTTP/SOCKS دارد، نه TUN؛ قانون برنامه فقط روی ترافیک واردشده به همین پروکسی اثر می‌گذارد و VPN دیگری را کنترل نمی‌کند. بسیاری از بازی‌ها اصلاً پروکسی ویندوز را استفاده نمی‌کنند و از قبل مستقیم هستند. پردازش‌های محافظت‌شده، برنامه‌های با دسترسی بالاتر یا EXE اشتباه ممکن است قابل تشخیص نباشند؛ اگر تشخیص شکست بخورد، اعلان کوتاه نمایش داده می‌شود و ترافیکِ بدون قانون همچنان پروکسی می‌ماند.

پینگ سرور، بررسی IP و کشور و آیکون‌های ده سرویس همیشه مسیر پروکسی را آزمایش می‌کنند؛ برای بررسی استثنا، از داخل همان سایت یا برنامه نتیجه اتصال را بررسی کنید. برای لغو همه استثناها، کلید اصلی بخش ۱۴ را خاموش و پس از اعمال دوباره وصل شوید.

## برگشت به نسخه قبلی

Quit کنید و فایل‌های برنامه را از کپی پوشه قبلی برگردانید؛ پوشه داده‌ها را حذف نکنید. ترجیحات جدید در نسخه قبلی نادیده گرفته می‌شوند.

## وضعیت بررسی

اعتبارسنجی و تست‌های محلی با Qt و هسته واقعی Xray روی لینوکس انجام شده‌اند. اجرای رابط و تشخیص پردازش روی ویندوز ۱۱ در این محیط قابل آزمایش مستقیم نیست. تست تطبیق پردازش در میزبان لینوکسی به دلیل محدودیت netlink قابل تکمیل نبود؛ پیکربندی آن توسط هسته پذیرفته و رفتار هشدار آن آزمایش شده است.
