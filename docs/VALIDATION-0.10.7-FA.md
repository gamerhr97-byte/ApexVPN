# گزارش ساخت Apex VPN 0.10.7

- Python source با `compileall` بررسی شد و native launcher و host با Zig x64 از کد فعلی ساخته شدند.
- NSIS نصاب کامل تک‌فایلی 0.10.7 را از payload کامل offline تولید کرد. CRC و hash تمام ۳۱۷۲ فایل payload بعد از استخراج پاس شد؛ لانچرها و host نیز PE x64 با resource نسخه 0.10.7 هستند.
- هیچ تست پینگ اینترنتی، تست واحد، نصب واقعی Windows یا اجرای Win+R در این محیط اجرا نشده است.
- پاک‌سازی کاتالوگ فقط در اولین اجرای این نسخه انجام می‌شود، پشتیبان می‌سازد و نشان تکمیل را پس از ذخیرهٔ موفق کاتالوگ ثبت می‌کند. Localهای دستی می‌مانند؛ علاقه‌مندی‌های وابسته از ساب جدا می‌شوند و سایر نودهای ساب‌های شخصی پاک می‌شوند.
- درخواست EcoQoS محدود به پنجرهٔ مخفی/minimize و زمان بیکاری است. Windows Task Manager نشان را بر اساس QoS سیستم رسم می‌کند؛ به‌صورت دستی نقاشی یا جعل نمی‌شود. Windows 10 ممکن است نام LowQoS نشان دهد.
- اجرای Setup، آپگرید، صفحهٔ حذف، App Paths، DPAPI، QoS و WinINET باید روی Windows بازبینی شوند. نصاب امضای ناشر ندارد.
