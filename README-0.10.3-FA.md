# Shadow Box 0.10.3

این بازبینی دو خروجی دارد: سورس و بسته کامل پرتابل Windows x64. پرتابل شامل ShadowBox.exe، میزبان بومی، Python/Qt، Xray، sing-box و وابستگی‌هاست؛ نصب Python جداگانه لازم نیست. **اجرای واقعی این خروجی روی Windows در محیط ما تأیید نشده است.** این بسته نصاب نیست و امضای ناشر ندارد.

## اجرای پرتابل

کل ZIP را استخراج و `NekoRayNext/ShadowBox.exe` را اجرا کنید. برنامه را از داخل ZIP اجرا نکنید. نام پوشه/داده قدیمی برای سازگاری حفظ شده است. برای ارتقای پرتابل قبلی، ابتدا از پوشه data نسخه پشتیبان بگیرید؛ data شخصی داخل فایل جدید نیست و نباید حذفش کنید. نسخه نصب‌شده قبلی و پرتابل ممکن است داده‌های جدا داشته باشند.

برای اجرای سورس، DEVELOPMENT.md را بخوانید و علاوه بر وابستگی‌های قبلی، هستهٔ قفل‌شدهٔ sing-box را با tools/download_singbox.py دریافت کنید. سورس به‌تنهایی runtime پرتابل را ندارد.

## تغییرات قابل بررسی

1. آیکون‌های حلقه‌ای عمومی حذف شدند. PNG فاوآیکون ۲۰۰ سایت در assets/services ذخیره شده؛ تصویر مرجع service-icons-reference.png از همین تصاویر ساخته شده است. برای ۱۰۰ مقصد فعال از تصاویر واقعی سایت‌ها استفاده می‌شود؛ این‌ها فاوآیکون‌اند و ممکن است چند محصول یک شرکت فاوآیکون یکسان داشته باشند. هیچ آیکونی هنگام مصرف برنامه دانلود نمی‌شود. منابع در sources.json ثبت شده‌اند.
2. پنل ثابت و جمع‌وجور، با ۱۰۰ مقصد، آیکون خوانا، جست‌وجو و tooltip کوتاه؛ شمارنده 1/1 · 39 و ردیف دکمه‌های صفحه حذف شدند. فهرست بزرگ سرورها با پیمایش پنجره‌ای ۲۰۰ ردیفی نمایش داده می‌شود.
3. تست عادی سایت‌ها: ۵ HTTPS و ۹۵ TCP/HTTP CONNECT، بدون دانلود صفحه یا اندازه‌گیری پینگ برای آن ۹۵ مقصد. تیک برای آن‌ها فقط برقراری اتصال را نشان می‌دهد، نه کارکرد اکانت یا اپ. کلیک روی آیکون یا راست‌کلیک → Ping، بررسی HTTPS درخواستی می‌گیرد. Pin to first five آن سایت را جای یکی از ۵ سایت ابتدای پنل می‌گذارد و این ۵ سایت همیشه HTTPS می‌گیرند. انتخاب‌ها پس از بازکردن برنامه حفظ می‌شوند. بررسی ضروری خود تونل و درخواست‌های صریح IP خارج از این نسبت ۵/۹۵ هستند.
4. پیش‌فرض تست گروه سرورها **Quick · TCP** است: ۱۲۸ کارگر، قابل تنظیم تا ۲۵۶؛ timeout اتصال ۱٫۵ ثانیه. مقصد host/port تکراری یک بار تست می‌شود و نتیجه برای پروفایل‌های آن مقصد به‌کار می‌رود. این تست احراز هویت، UDP یا سلامت کامل تونل را ثابت نمی‌کند. Lightweight عمداً تست را تک‌کارگری می‌کند.
5. گزینه HTTPS برای تأیید تونل و گزینه Quality · 100 sites برای بررسی ۱۰۰ مقصد هر تونل جدا هستند. منوی راست‌کلیک سرور → Check 100 sites، کیفیت فقط همان سرور را بررسی می‌کند. بررسی کامل هزاران تونل همچنان هزینه زمانی/شبکه دارد؛ سریع‌کردن TCP جای تأیید رمز و TLS نیست.
6. نشان Gemini از فاوآیکون خود Gemini استفاده می‌کند. نشان دوم تیک است، نه ستاره رنگی. بیش از ۷۵ موفقیت (یعنی حداقل ۷۶ از ۱۰۰) تیک دسترسی می‌دهد. تیک دسترسی مدرک reputation آی‌پی نیست. نشان‌ها در تست ساده پاک نمی‌شوند و با تازه‌سازی صریح بررسی سایت‌ها یا نتیجه کامل تازه جایگزین می‌شوند. نتایج سایت‌های اتصال فعال به‌ازای پروفایل ذخیره می‌شوند؛ تغییر خودکار IP یک ارائه‌دهنده بدون بررسی تازه از روی این کش تشخیص داده نمی‌شود.
7. ترتیب/جهت کنترل‌های اصلی، جدول و پنل سایت‌ها مستقل از فارسی ثابت است؛ تنظیمات خودش RTL می‌شود. مقادیر IP و پارامترهای شبکه LTR هستند. نام فارسی سرور حفظ می‌شود.
8. گزینه Remove servers that do not work در تنظیمات Subscriptions اضافه و **پیش‌فرض خاموش** است. فقط پس از تست کاملِ لغونشده، Failed/Timeout/Refusedهای همان گروه حذف می‌شوند؛ Unsupported و سرور فعال حفظ می‌شوند؛ قبل از حذف backup گرفته می‌شود. شکست TCP می‌تواند موقت باشد.
9. راست‌کلیک بخش IP → Copy IP. اگر هنوز IP درخواست نشده، کپی غیرفعال است. همان منو گزینه Check IP reputation دارد: با کلید API خودتان از ipapi.is گزارش مستقل abuse/Tor/proxy/VPN/datacenter می‌گیرد. کلید در این درخواست استفاده می‌شود و در فایل/لاگ ذخیره نمی‌شود؛ امکان استفاده از متغیر محیطی SHADOWBOX_IPAPI_KEY هم هست. نتیجه ناقص/خطا «تمیز» فرض نمی‌شود. هیچ API به‌تنهایی تمیزی قطعی آی‌پی را تضمین نمی‌کند.
10. مسیر هسته sing-box به Engine با همان نظارت فرایند، pipe خصوصی، تأیید اجباری HTTPS و بازیابی پروکسی اضافه شد. Hysteria2، TUIC، AnyTLS، SOCKS4 و زیرمجموعه‌هایی از Hysteria/SSH/Naive مسیر دارند؛ Clash YAML و sing-box JSON به پروفایل‌های خروجی مستقل تبدیل می‌شوند. جزئیات و موارد هنوز پشتیبانی‌نشده در PROTOCOL-SUPPORT-FA.md هستند. **پشتیبانی تمام پروتکل‌ها تکمیل نشده است.**

برای واردسازی‌های چندسروری YAML/JSON، متن مشترک منبع فقط یک بار در همان کاتالوگ محافظت‌شده ذخیره می‌شود؛ بازکردن و کپی پروفایل همچنان متن اصلی را در اختیار دارد. کاتالوگ‌های قدیمی قابل خواندن‌اند.

## بررسی پیشنهادشده

- پنل سایت‌ها را با VPN و بدون آن باز کنید؛ ۹۵ مقصد باید بدون عدد پینگ باشند تا خودتان Ping بزنید. روی یک سایت Pin بزنید، برنامه را دوباره باز کنید و جای آن را بررسی کنید.
- یک سرور را Quick TCP و سپس از راست‌کلیک با Check 100 sites آزمایش کنید؛ نشان‌های قبلی نباید با تست ساده ناپدید شوند.
- زبان را فارسی کنید؛ پلاس چپ، تنظیمات راست و داده‌های شبکه قابل خواندن بمانند.
- روی IP راست‌کلیک و آن را کپی کنید. گزارش اعتبار IP به کلید معتبر API و دسترسی به ارائه‌دهنده نیاز دارد.
- برای لینک Hysteria2 دارای insecure=1 توضیح بخش امنیت در PROTOCOL-SUPPORT-FA.md را بخوانید.

گزارش آزمون‌ها در docs/VALIDATION-0.10.3-FA.md و محدودیت واقعی هسته‌ها در ماتریس پروتکل‌ها آمده‌اند. زمان واقعی ۱۰هزار سرور به DNS، شبکه، timeout و نوع تست وابسته است؛ عدد بنچمارک مصنوعی، پینگ اینترنت واقعی نیست.
